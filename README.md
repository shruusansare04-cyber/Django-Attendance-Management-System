
# Django Attendance Management System

## About the Project
The Django Attendance Management System is a web-based application developed using Python and Django. It helps manage students, teachers, subjects, and attendance records in one place.

This is my first Django project, developed as part of my practical learning journey.

## Features
- Student Management
- Teacher Management
- Subject Management
- Mark Attendance
- View Attendance History
- Attendance Percentage
- Dashboard Pages
- User Login Pages

## Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap

## Project Structure
- `app/` — Application code, models, views, and templates
- `attendance_system/` — Main Django project settings and URLs
- `manage.py` — Django management utility
- `requirements.txt` — Python dependencies

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/shruusansare04-cyber/Django-Attendance-Management-System.git
   ```

2. Open the project folder:

   ```bash
   cd Django-Attendance-Management-System
   ```

3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Apply database migrations:

   ```bash
   python manage.py migrate
   ```

5. Start the development server:

   ```bash
   python manage.py runserver
   ```

6. Open `http://127.0.0.1:8000/` in your browser.
